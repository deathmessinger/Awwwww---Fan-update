# Adibags_professions
Adibags mod for professions sorted by expansion

!!This is a work in progress!!

It will sort all the items gathered by Skinning, Mining, Herbalism, Fishing and all Cloth
either by the profession or by the Expansion in your bags, bank and reagent bank

It will also sort all reagents needed by each Profession either by profession or expansion.
